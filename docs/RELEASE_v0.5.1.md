# XiangQiLens v0.5.1

按实机反馈做的调整：**移除自动接盘**、**「新局」改为停掉分析后由你点「分析」**、
**四项默认值调整**。

---

## 1. 移除「自动接盘」功能

上一版新增的自动接盘（模板匹配点「再来一局」+ 自动关弹窗）**整体删除**。

- 面板、模板录制（截图框选对话框）、模板匹配、点击逻辑、参数持久化全部移除。
- 为它而做的**终局判定**（无真合法着法 / 停滞兜底）也一并移除 —— 没有别的消费者了。
- 连带删掉：`game_state` 信号、`post_restart` / `apply_restart_params`、
  `_check_game_over` / `_verify_restart` / `_do_restart` / `_try_click_restart`、
  `RegionSelectDialog` / `_RegionLabel`、`tools/test_gameover.py`。

> 打包/发布相关的 `_current_window()`（修「框选点了没反应」的那个）**保留**，
> `start()` 现在也走它。

**测试**：原来 `test_gameover.py` 里最有价值的一条回归 ——
**伪合法 vs 真合法** —— 迁到新文件 `tools/test_legality.py` 并扩充（22 条断言）：

- 双车杀局面里 3 个「送将」着法全部通过 `is_legal_move`（**伪合法**），
  但全部被 `is_strict_legal_move` 拒绝；
- 将帅照面、走子方颜色（轮次自纠的前提）、非法 FEN 的受控失败。

---

## 2. 「新局」改为：停掉分析 → 由你点「分析」开始

上一版点「新局」是**原地重置、分析继续跑**。现在改成：

| 点「新局」时 | 行为 |
|---|---|
| 正在分析 | **停掉分析**，状态栏提示「已开新局 —— 点「分析」开始（会自动判断我方执子）」 |
| 已停止 | 记下「待开新局」，同样提示点「分析」开始 |

即：**「新局」是准备动作，什么时候开局由你决定**；点「分析」后 Worker 用全新的
局面跟踪起步，并立刻自动判断我方执子。

> 因为「新局」现在一定会停掉 Worker，下一次「分析」是**全新的 Worker**，
> 所以原来那套「往运行中的 Worker 发重置命令」的通道（`post_newgame` /
> `apply_newgame`）已无消费者，一并删除。

## 3. 默认值调整

| 项 | 旧默认 | **新默认** |
|---|---|---|
| 走棋模式 | 关闭自动走棋 | **启动走棋（真点落子）** |
| 引擎线程 Threads | 8 | **2** |
| 引擎哈希 Hash | 256 | 256（不变） |
| 识别稳定（动画抑制） | 开 | **关** |

- 走棋模式默认「真点」后，`automove.json` 里存的 `mode` 会**被沿用**
  （包括 `real`）；旧配置没有 `mode` 键时也落到真点。
- **不想让它自动落子**：把走棋模式选回「关闭自动走棋」，或直接按
  「紧急停止自动走棋」。
- 动画抑制默认关掉后，天天象棋吃子时的「吃」字动画抑制**不再生效** ——
  需要时在「识别稳定」面板勾上「等画面静止后再识别」。

---

## 4. 顺带修的一处

`app_backend.has_no_legal_moves` 现在会先确认**双将都在场**再判终局：
`cchess` 的 `no_moves()` 在找不到己方的将时直接返回 `True`，
非法/残缺 FEN 会被误判成「将死」。

## 已知限制

- 移除自动接盘后，**一局结束需要你手动点平台的「再来一局」**，
  再点本程序的「新局」→「分析」开始下一局。
- 「自动判断我方执子」仍只在**点「分析」之后**生效（需要识别模型跑起来）。
