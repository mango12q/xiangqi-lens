# XiangQiLens v0.5.1 实机测试清单

> 版本：v0.5.1
> 相对 v0.5.0 的变化：**移除自动接盘** · **「新局」改为停掉分析后由你点「分析」** ·
> **四项默认值调整**（自动走棋默认真点 / 线程 2 / 哈希 256 / 动画抑制默认关）

---

## 0. 准备

```bash
python app_vision.py          # 或双击 启动XiangQiLens.bat
```

顶部「目标窗口」会自动选中标题含「象棋」的窗口；打开天天象棋 / JJ象棋进到对局界面。

---

## 1. 先确认默认值都对  ★本轮改动

打开程序后**什么都别点**，直接看：

| 位置 | 应该是 |
|---|---|
| 右栏「自动走棋」→ 走棋模式 | **「启动走棋（真点落子）」被选中** |
| 右栏「引擎参数」→ 线程 Threads | **2** |
| 右栏「引擎参数」→ 哈希 Hash | **256** |
| 右栏「识别稳定」→ 等画面静止后再识别 | **未勾选**（默认关） |
| 右栏有没有「自动接盘」面板 | **应该没有了** |

> ⚠️ 默认是真点：点「分析」就会真的替你落子。**第一次用请先把走棋模式切到
> 「预览模式（只算不点）」**，确认坐标无误再切回来。

---

## 2. 新局 → 分析  ★本轮改动

| 步骤 | 预期 |
|---|---|
| 1. 进对局界面（红方还没动子 / 或还在匹配中） | — |
| 2. 点顶部 **「新局」** | 状态栏：「**已开新局 —— 点「分析」开始（会自动判断我方执子）**」 |
| 3. 如果程序本来在跑 | 会**先停掉分析**，按钮从「停止」变回「分析」 |
| 4. 自己点 **「分析」** | 开始分析 |
| 5. 等棋盘出现 | 状态栏：「已自动判断我方执子：我方执红/执黑（红/黑方底线在画面下方）」 |
| 6. 看「我方执子」下拉框 | **被自动回填成正确的一方** |

**不通过时**：状态栏一直显示「暂时判不了（关键点不成四边形）」→ 确认对局界面真的开着、没被挡住。

---

## 3. 自动走棋  ★默认已开启，注意安全

| 步骤 | 预期 |
|---|---|
| 1. 先切到「**预览模式（只算不点）**」 | 红色运行指示显示「（预览）」 |
| 2. 点「分析」 | 「将点击的着法与屏幕坐标」显示出来，坐标落在正确交叉点 |
| 3. 切到「**启动走棋（真点落子）**」 | 轮到我方时自动落子 |
| 4. 开局第一手（盘面还是初始局面） | 你执红 → 正常落子；你执黑 → **不落子**（等红方走完），这是轮次闸门，正常 |
| 5. 重启程序 | 走棋模式**沿用上次的选择**（存在 `automove.json`） |

**不想让它自动落子**：选「关闭自动走棋」，或按「紧急停止自动走棋」。

---

## 4. 识别稳定（动画抑制）★默认已关

| 步骤 | 预期 |
|---|---|
| 1. 默认状态 | 面板里「等画面静止后再识别」**未勾选** |
| 2. 制造一次吃子 | 因为默认关，**不会**出现「画面变化中…」的暂停提示 |
| 3. 如果天天象棋还是因为「吃」字动画识别出错 | **手动勾上**「等画面静止后再识别」再试 |

> 之前实机反馈动画抑制很成功，但按你的要求现在默认关闭 —— 需要时手动开。

---

## 5. 开局库（.obk）

| 步骤 | 预期 |
|---|---|
| 1. 「开局库」面板 → 浏览 → 选 `云霄剑诀7.5.obk` | 状态行：「已加载：云霄剑诀7.5.obk · obk（170986 条记录）」 |
| 2. 库着策略选「库着优先」 | — |
| 3. 点「分析」开一局 | 「当前命中库着：…」；「当前建议」栏末尾出现 **【开局库】** 标记 |

---

## 6. 轮次自纠（回归）

| 步骤 | 预期 |
|---|---|
| 1. 若你执黑：让红方先走一步 | 状态栏「该谁走」自动变成 **黑方走**，不需要手动设置 |

---

## 7. 异常可见化（回归）

任何按钮点了没反应，都应该变成**弹窗**「程序内部错误」+ 生成 `XiangQiLens_crash.log`。

---

## 优先级

| 优先级 | 项目 | 理由 |
|---|---|---|
| **P0** | 1. 默认值 / 2. 新局→分析 | 本轮直接改动，一开程序就能看 |
| **P0** | 3. 自动走棋 | **默认变真点了**，先确认安全（建议先预览） |
| **P1** | 4. 动画抑制默认关 | 确认关掉后天天象棋会不会又误识别 |
| **P1** | 5. 开局库 | 上轮新增，这轮没动 |
| **P2** | 6/7 回归 | 逻辑未变 |
