# XiangQiLens v0.5.0 实机测试清单

> 版本：v0.5.0（`3cdeb31` / Release 已发布）
> 目标：验证本轮新做的 4 项功能在**真实对局**里的表现。
> 用法：按顺序做，每项都写了「步骤 / 预期 / 不通过时怎么办」。

---

## 0. 准备

**用哪一版跑？**

| 方式 | 命令 / 路径 |
|---|---|
| 源码（推荐，改起来方便） | `python app_vision.py` 或双击 `启动XiangQiLens.bat` |
| 发行包 | 从 [Release](https://github.com/mango12q/xiangqi-lens/releases/tag/v0.5.0) 下 `XiangQiLens-v0.5.0.zip`，解压后跑 `XiangQiLens.exe` |

> ⚠️ 发行包要**整个目录**一起用，exe 需要同级的 `xq_research/`。

**开一局之前先做**：

1. 顶部「目标窗口」确认选中的是象棋窗口（标题含「象棋」那个，会自动选中）。
2. 打开 `天天象棋` / `JJ象棋`，进到**对局界面**（不是大厅）。

## 1. 新局 · 自动判断我方执子  ★本轮新做，必测

**为什么测**：这是本轮新功能，逻辑依赖棋盘朝向，只有实机能验证。

| 步骤 | 预期 |
|---|---|
| 1. 进对局界面（**红方还没动子**，或还在匹配中） | — |
| 2. 点顶部 **「新局」** | 状态栏显示「已开新局：正在自动判断我方执子…」 |
| 3. 等棋盘出现（匹配中时会自动重试） | 状态栏变成「已自动判断我方执子：我方执红/执黑（红/黑方底线在画面下方）」 |
| 4. 看「我方执子」下拉框 | **被自动回填成正确的一方** |

**判定依据**：象棋客户端一律把**己方**摆在画面下方。所以如果你执黑，你的黑子在下 → 判「我方执黑」。

**不通过时**：
- 状态栏一直显示「暂时判不了（关键点不成四边形）」→ 说明识别没定位到棋盘，先确认对局界面真的开着、没被别的窗口挡住。
- 判反了 → 立刻告诉我，并附上「状态栏原文 + 你实际执哪一方」，这是几何判据的问题。

## 2. 自动接盘  ★唯一完全没实机验证过的功能，最优先

**为什么测**：上一轮因为一个 bug 导致按钮点了没反应，你一直没能录成模板；现在修好了，但**整条链路从未实机跑过**。

### 2.1 录模板

| 步骤 | 预期 |
|---|---|
| 1. **先点「停止」**（如果正在分析） | — |
| 2. 点 **「① 框选『再来一局』按钮」** | 弹出一张目标窗口截图（不再是「点了没反应」） |
| 3. 在图上**拖拽框住**「再来一局」按钮（框住文字即可）→ 点「确定」 | 状态栏「模板已保存：restart_btn.png（宽×高）」；面板变「『再来一局』：✅ 已录模板」 |
| 4. 点 **「② 框选『关闭弹窗』按钮」** | 再弹一张截图 |
| 5. 拖拽框住弹窗的 **✕**（或「确定」）→ 确定 | 面板变「『关闭弹窗』：✅ 已录模板」 |
| 6. 勾选 **「启用自动接盘」** | — |

> 天天象棋各种弹窗（段位升级 / 财源广进 / 获得徽章）的 ✕ **位置一致**，
> 一个模板就能关掉全部。JJ象棋若没有弹窗可以不录第 ② 步。

**⚠️ 运行中点框选** → 应弹「请先点「停止」再标定」，这是**正常的**（防止和识别线程抢抓帧）。

### 2.2 实机跑一局

| 步骤 | 预期 |
|---|---|
| 1. 点「分析」跑起来，正常下完一局 | — |
| 2. 对局结束 | 面板显示「本局已结束（无合法着法（将死/困毙））」 |
| 3. 等待 | 状态栏「自动接盘：找到「再来一局」(相似度 0.9x)」→「已点击」 |
| 4. 有弹窗时 | 先出现「自动接盘：先关掉弹窗」，逐个关掉后再点「再来一局」 |
| 5. 结果 | 自动开新一局，面板「已接盘：…」 |

**不通过时**：
- 「没能找到「再来一局」按钮」→ 把 **「匹配阈值」从 0.80 调低到 0.70** 再试；仍不行就重新录模板（框选时框紧一点、只框文字）。
- 「点击后未检测到新对局」→ 模板可能框错了位置，重录。
- 对手认输 / 超时结束（不是将死）→ 默认**不会**触发（那需要开启「同时用『长时间停滞』兜底」，但有误判风险，自己权衡）。

## 3. 开局库（.obk）  ★本轮新增格式

| 步骤 | 预期 |
|---|---|
| 1. 展开「开局库（应用层实现）」面板 → 点「浏览…」 | 文件对话框 |
| 2. 选 `C:\Users\mango\Downloads\云霄剑诀7.5.obk` | 状态行显示「已加载：云霄剑诀7.5.obk · obk（170986 条记录）」 |
| 3. 「库着策略」选「库着优先」；「库深度」保持 40 | — |
| 4. 点「分析」，开一局 | 「当前命中库着：兵七进一（c3c4）权重 xxx」；「当前建议」栏末尾出现 **【开局库】** 标记 |
| 5. 开自动走棋（预览） | 开局几步走的是库着（和引擎最佳着不一定相同，这是正常的） |

**不通过时**：显示「加载失败」→ 把报错原文发我。

## 4. 轮次自纠（回归确认）

**为什么测**：本轮删掉了「先手」下拉，改成自动推断 + 自纠。

| 步骤 | 预期 |
|---|---|
| 1. 若你**执黑**：让红方先走一步 | 状态栏「该谁走」应变成 **黑方走**（自动纠正，不需要你设置） |
| 2. 若你**执红**：直接走 | 全程正常 |

**不通过时**：状态栏一直刷「局面变化无法解释，已挡下」→ 告诉我。

---

## 5. 自动走棋（回归确认）

**为什么测**：本轮改了轮次默认值、加了「轮次硬闸门」，怕误伤。

| 步骤 | 预期 |
|---|---|
| 1. 走棋模式选「**预览模式（只算不点）**」 | 红色运行指示显示「（预览）」 |
| 2. 看「将点击的着法与屏幕坐标」 | 坐标落在正确交叉点 |
| 3. 改选「**启动走棋（真点落子）**」 | 能正常落子 |
| 4. 开局第一手（盘面还是初始局面） | 若你执红 → 正常落子；若你执黑 → **不会**落子（等红方走完）← 这是新加的闸门，正常 |

---

## 6. 动画抑制（回归确认）

**为什么测**：本轮只加了「最长抑制兜底」，核心逻辑没动，快速确认没退化。

| 步骤 | 预期 |
|---|---|
| 1. 制造一次吃子 | 状态栏短暂出现「画面变化中（x%），等待稳定后再识别…」 |
| 2. 动画结束后 | 正常恢复识别，**不误判** |
| 3. 若盘面有持续动画 | 最多 5 秒后会强制放行一帧（不再永久卡住） |

---

## 7. 异常可见化（新增兜底，顺手验一下）

现在**任何按钮点了没反应**都应该变成**弹窗**「程序内部错误」+ 写日志。

| 步骤 | 预期 |
|---|---|
| 1. 故意制造异常（比如窗口被完全遮挡时点框选） | 弹「抓帧失败…」提示，或弹「程序内部错误」 |
| 2. 若弹了「程序内部错误」 | 应用目录下会生成 `XiangQiLens_crash.log`，**把这个文件发我** |

## 优先级建议

| 优先级 | 项目 | 理由 |
|---|---|---|
| **P0** | 2. 自动接盘 | 唯一完全没实机验证过的功能，且上一轮就是被 bug 卡住的 |
| **P0** | 1. 新局 · 自动判断执子 | 本轮新做，几何判据只有实机能验 |
| **P1** | 3. 开局库 .obk | 本轮新增格式，涉及外部文件 |
| **P1** | 5. 自动走棋 | 本轮动过轮次默认值，怕误伤 |
| **P2** | 4. 轮次自纠 / 6. 动画抑制 / 7. 异常兜底 | 逻辑简单或本轮几乎没动 |
