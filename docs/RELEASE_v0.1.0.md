# XiangQiLens v0.1.0

首个可分发版本。把棋盘从屏幕里「读」出来，交给 Pikafish 分析，并在棋盘上画出推荐走法箭头。

**不含自动走子** —— 只给建议，落子由你自己操作。

![界面](https://raw.githubusercontent.com/mango12q/xiangqi-lens/main/docs/screenshot.png)

---

## 下载与运行

下载 `XiangQiLens-v0.1.0.zip`，解压后双击 **`XiangQiLens.exe`**。

**无需安装 Python 或任何依赖** —— 运行时已打包进 exe。

> ⚠️ 请**解压后整目录使用**，不要只把 exe 单独拷出来。exe 需要同级的
> `xq_research/` 目录提供识别模型与引擎（约 95MB）。

### 系统要求

- Windows 10 / 11（64 位）
- 建议独显或支持 DirectML 的核显；纯 CPU 可用但识别慢约 6 倍

---

## 快速开始

1. 打开对局窗口（微信小程序、桌面客户端均可），让棋盘可见
2. 启动 `XiangQiLens.exe`
3. 在「目标窗口」里选**棋局窗口本身**（如 `JJ象棋 [Chrome_WidgetWin_0]`），
   不要选整个聊天/宿主窗口
4. **设置「我方执子」** —— 你在这一局执红还是执黑，**选错会让所有建议失效**
5. 设置「先手」（当前轮到谁走）
6. 点「开始」

### 「我方执子」和「先手」是两回事

| 选项 | 决定什么 | 选错的后果 |
|---|---|---|
| **我方执子** | 棋盘朝向（画面是否上下颠倒） | 局面整个颠倒，建议全部无效 |
| **先手** | 首帧轮到谁走 | 首次分析不准，之后会自动校正 |

识别模型假设红方在画面下方。你执黑时棋盘是上下颠倒的，程序会自动把
90 格矩阵旋转 180° 还原。

## 功能

| 能力 | 说明 |
|---|---|
| **后台截图** | 用 `PrintWindow` 截取窗口，**不要求窗口可见、可被遮挡**；失败自动回退屏幕抓取 |
| **走法箭头** | 绿色粗箭头 = 最佳着法，蓝色细箭头 = 候选变化，直接画在棋盘上 |
| **胜率显示** | 开启引擎 `UCI_ShowWDL`，显示「我方胜率 58% · 和 30% · 对方 12%」及局面判断 |
| **中文着法** | `h2e2` → `炮二平五` |
| **轮次推断** | 局面差分 + 引擎着法合法性自纠 |
| **四道识别闸门** | 见下，任何一道不过都不会把垃圾局面送进引擎 |
| **失败可见** | 左栏显示识别程序实际看到的棋盘，出问题一眼看得出 |

### 四道识别闸门

每帧识别结果依次通过：

1. **棋盘几何校验** —— pose 模型在画面没棋盘时也会输出 4 个点且常退化成一条线
2. **局面严格校验** —— 将帅各一、数量上限、九宫、照面（`cchess` 对缺子局面太宽松）
3. **棋规校验** —— `cchess` 构造与着法规则
4. **演化校验** —— 新局面必须能由上一局面走一步合法着法得到，挡住单帧误识别

## 实测数据

识别性能（683×1253 窗口，RTX 4070）：

| 配置 | pose | cls | 完整单帧 |
|---|---|---|---|
| CPU 推理 | 13.8ms | 872.5ms | 979ms |
| DirectML | **4.1ms** | **128.0ms** | **170ms** |

引擎：Pikafish 2026-09-06，开局 `depth 25` 约 1.2 秒。

## 已知限制

- **识别会偶发出错**：模型在个别棋子/皮肤上会误判（例如红傌读成红炮）。
  闸门 4 能挡住瞬时错误，但若误判连续稳定出现，兜底机制会在 6 帧后采信它。
- **窗口不能最小化**：最小化时截图拿不到棋盘。程序会检测并提示。
- **仅 Windows**：截图、DPI 与窗口状态检测依赖 Win32 API。
- **不含自动走子**：这是刻意设计，只做识别与建议。
