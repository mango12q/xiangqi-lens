# XiangQiLens v0.2.0

把棋盘从屏幕里「读」出来，交给 Pikafish 分析，并在棋盘上画出推荐走法箭头。

**不含自动走子** —— 只给建议，落子由你自己操作。

![界面](https://raw.githubusercontent.com/mango12q/xiangqi-lens/main/docs/screenshot.png)

---

## 下载与运行

下载 `XiangQiLens-v0.2.0.zip`，解压后双击 **`XiangQiLens.exe`**。

**无需安装 Python 或任何依赖** —— 运行时已打包进 exe。

> ⚠️ 请**解压后整目录使用**，不要只把 exe 单独拷出来。exe 需要同级的
> `xq_research/` 目录提供识别模型与引擎（约 95MB）。

系统要求：Windows 10 / 11（64 位）。

## v0.2.0 更新内容

### 修复：执黑时局面颠倒

识别模型训练时假设红方在画面下方。你执黑时整个棋盘是上下颠倒的，
之前版本会输出完全错误的局面、走法建议也全反了。

现在新增「**我方执子**」选项，执黑时自动把 90 格矩阵旋转 180°
（上下翻转 + 每行左右翻转；只做上下翻会得到左右镜像的非法局面）。

> ⚠️ 「我方执子」和「先手」是**两回事**，都要设对：
> 「我方执子」决定棋盘朝向，「先手」决定首帧该谁走。前者选错会让所有建议失效。

### 新增：胜率显示

开启引擎的 `UCI_ShowWDL`，显示人类可读的局面评估：

> 我方胜率 58% · 和 30% · 对方 12%（我方稍优）

比裸的 `+0.75` 直观得多 —— 分数看不出「和棋概率 92%」，胜率一眼就懂。
视角会按你执红还是执黑自动换算。

### 新增：初始化进度提示

首次启动需要加载模型（3 个文件约 90MB）、预热推理、启动引擎，冷启动可能
要十几到几十秒。之前版本这段时间界面全黑且无提示，容易被误认为卡死。

现在状态栏会依次显示：

```
① 加载识别模型…（首次约 10~30 秒，请稍候）
② 预热识别模型…（首次推理较慢，属正常）
③ 启动 Pikafish 引擎…
```

其中「预热」是主动做的：DirectML 首次推理要编译着色器，耗时远超后续正常帧。
放初始化里做掉，进入识别后的耗时才是真实水平。

### 新增：运行日志

exe 同级会生成 `XiangQiLens.log`，记录初始化步骤、每次采纳的局面、
以及各种被拦下的原因。出问题时看它即可，不需要靠猜。

### 新增：窗口状态检测

窗口最小化时 `GetWindowRect` 只返回标题栏尺寸，截图拿不到棋盘。之前会
表现为「局面不合法」，让人摸不着头脑。现在会明确提示：

> 目标窗口已最小化，请先还原窗口

窗口下拉框也会列出最小化的窗口并标注 `[已最小化]`。

### 界面调整

- 窗口标题与日志中显示版本号
- 技术指标（识别耗时、置信度、护栏状态）移到状态栏，主要位置留给胜率

## 功能总览

| 能力 | 说明 |
|---|---|
| **后台截图** | 用 `PrintWindow` 截取窗口，**不要求窗口可见、可被遮挡**；失败自动回退屏幕抓取 |
| **走法箭头** | 绿色粗箭头 = 最佳着法，蓝色细箭头 = 候选变化，直接画在棋盘上 |
| **胜率显示** | 引擎 WDL 输出，视角按我方执子自动换算 |
| **中文着法** | `h2e2` → `炮二平五` |
| **轮次推断** | 局面差分 + 引擎着法合法性自纠 |
| **执黑适配** | 自动旋转 180° 还原标准朝向 |
| **四道识别闸门** | 任何一道不过都不会把垃圾局面送进引擎 |
| **失败可见** | 左栏显示识别程序实际看到的棋盘 |

### 四道识别闸门

每帧识别结果依次通过：

1. **棋盘几何校验** —— pose 模型在画面没棋盘时也会输出 4 个点且常退化成一条线
2. **局面严格校验** —— 将帅各一、数量上限、九宫、照面（`cchess` 对缺子局面太宽松）
3. **棋规校验** —— `cchess` 构造与着法规则
4. **演化校验** —— 新局面必须能由上一局面走一步合法着法得到，挡住单帧误识别

## 实测数据

识别性能（683×1253 窗口，RTX 4070）：

| 配置 | pose | cls | 完整单帧 |
|---|---|---|---|
| CPU 推理 | 13.8ms | 872.5ms | 979ms |
| DirectML | **4.1ms** | **128.0ms** | **170ms** |

引擎：Pikafish 2026-09-06，开局 `depth 26` 约 1.2 秒。

## 已知限制

- **识别会偶发出错**：模型在个别棋子/皮肤上会误判（例如红傌读成红炮）。
  闸门 4 能挡住瞬时错误，但若误判连续稳定出现，兜底机制会在 6 帧后采信它。
- **窗口不能最小化**：最小化时截图拿不到棋盘。程序会检测并提示。
- **仅 Windows**：截图、DPI 与窗口状态检测依赖 Win32 API。
- **不含自动走子**：这是刻意设计，只做识别与建议。
